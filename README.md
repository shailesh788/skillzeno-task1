# Personal Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript. No package manager or build step is required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Personalize before publishing

1. Replace the sample name, monogram, city, bio, skills, project examples, education, and experience in `index.html`.
2. Change `hello@example.com` in both `index.html` and `script.js` to your email address.
3. Replace the sample social profile links and update the page title and description.

The contact form validates entries in the browser and opens the visitor’s default email app with a prefilled note. It does not submit to a server or store form data.

## Publish with GitHub Pages

Create a GitHub repository, add these files, and push them to the `main` branch. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`. GitHub Pages will provide the public URL after deployment.

## Files

- `index.html` — page content and structure
- `styles.css` — visual design and responsive layouts
- `script.js` — navigation, form validation, and interactions
